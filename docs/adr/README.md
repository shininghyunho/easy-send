# 아키텍처 결정 기록 (ADR)

판단이 갈릴 수 있었던 설계 결정만 기록한다 — "무엇을 검토했고 왜 이걸 골랐는지". 당연한 선택은 싣지 않는다.

| # | 결정 | 상태 |

| [001](001-프로토콜-자체설계-LocalSend-차용.md) | 프로토콜 자체 설계 + LocalSend v2 구조 차용 (완전 호환도, 완전 독자도 아님) | ✅ 확정 |
| [002](002-탐색-멀티캐스트-직접구현-브로드캐스트-병행.md) | 탐색 = UDP 멀티캐스트 직접 구현 + 서브넷 브로드캐스트 병행 (실기기 실측으로 개정) | ✅ 확정 |
| [003](003-처음부터-자체서명-HTTPS.md) | 전송 채널 = 처음부터 자체서명 HTTPS — 스파이크로 HTTP 퇴로 제거 | ✅ 확정 |
| [004](004-신뢰모델-TOFU-지문이-기기ID.md) | 신뢰 모델 = TOFU(PIN 없음), 인증서 지문이 곧 기기 ID | ✅ 확정 |
| [005](005-코어-격리-Rust-재구현.md) | 프로토콜 코어를 순수 패키지로 격리 → Rust로 통째 교체 (flutter_rust_bridge) | ✅ 확정 |

## 문서 형식

모든 문서는 두괄식으로 통일한다.

- 머리에 **상태 / 결정 / 대가** 3줄 요약
- 본문은 **배경 → 검토한 대안 → 결과(얻는 것 / 잃는 것·지켜야 할 것)** 순서
